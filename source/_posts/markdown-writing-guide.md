## 为什么是 Markdown

Markdown 用最简单的纯文本表达结构：一个 `#` 就是标题，一个 `-` 就是列表。它稳定、可移植、diff 友好，几乎被所有博客框架、笔记软件和代码平台支持。

下面是我日常写作最常用的一页速查表。

## 标题与段落

```markdown
# 一级标题
## 二级标题
### 三级标题

这里是段落。段落之间用空行分隔。
```

> 建议：一篇文章只用一个一级标题（即文章标题），正文从二级标题开始。

## 强调

```markdown
**加粗**
*斜体*
~~删除线~~
`行内代码`
```

效果：**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 列表

## 引用与分割线

```markdown
> 值得记住的一句话。

---
```

## Hexo 的 front-matter

每篇文章开头的两行 `---` 之间是元数据：

```yaml
---
title: 文章标题
date: 2026-11-13 09:30:00
updated: 2026-11-13 09:30:00   # 可选，显示「最后更新」
tags: [Hexo, 教程]            # 标签：多篇文章共用
categories: [技术]             # 分类：有层级
description: 一句话摘要，会显示在首页卡片
cover: /img/cover.png          # 可选，文章封面
top_img: /img/banner.png       # 可选，文章顶部大图
---
```

## 写作小习惯

1. **先写完，再修改**：初稿不必纠结措辞。
2. **一段只讲一件事**：移动端阅读更轻松。
3. **代码能跑通再贴**：读者会直接复制。
4. **标题写清楚「解决什么问题」**：比「随笔一则」有用得多。
